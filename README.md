# Financial Transparency and Corruption Research
ENG 220 — Group 11

## Overview
This project explores financial transparency and corruption through
data collection, analysis, and an interactive dashboard.

## Repository Structure
- `data/` — Project datasets and extracted information
- `scripts/` — Data collection and processing scripts
- `sources/` — Research references and source documentation
- `app.py` — Application code
- `streamlit_app.py` — Streamlit application code
- `SebastiansStuffWIP/` — Work in progress
- `thomas_doj/` — DOJ-related research and processing code
