# Data notes: large files not stored in the repository

These files are too large for GitHub. Download them yourself before running the MATLAB scripts.
Keep them in a local folder that is not committed (the MATLAB scripts read from the current folder).

## FAC (Federal Audit Clearinghouse) bulk CSVs
Used by `matlab/audit_findings.m` and `src/audits/fac_cuba_figures.py`.

- Download: https://www.fac.gov/data/download/current/
- The MATLAB file currently uses only `federal_awards.csv`, `findings.csv`, and `general.csv`.
  It may use the other files later, so downloading all of them is worth it (the download is slow).
- A small FAC summary export is stored in `data/raw/fac/`.

## Census county shapefile
Used by `matlab/unmatched_appropriations.m` to draw the county map.

- Download: https://www.census.gov/cgi-bin/geo/shapefiles/index.php?year=2026&layergroup=Counties+%28and+equivalent%29
- Place the extracted `.shp` files in the folder you run the script from.

## Files that are regenerated by scripts
- `data/raw/doj/nm_collection_progress.json` is produced by `src/doj/collect_doj_releases.py`.
- `data/interim/doj/nm_financial_candidates.json` is produced by `src/doj/screen_nm_articles.py`.
- `data/pdfs/` and `data/processed/pdf_extraction/` are git-ignored.
